# 🕶️ netrunner

**netrunner** is my personal cybersecurity portfolio.

It contains hands-on labs and projects I use to build and document my understanding of:

- 🖧 Network security fundamentals  
- ⚔️ Offensive and defensive security workflows  
- 🧪 Safe lab design and isolation  
- 📝 Clear technical documentation  

The focus of this repository is **learning by building** and **explaining decisions**.

## ⚖️ Scope & Ethics

All activities in this repository are performed exclusively within:

- Local virtualized environments  
- Intentionally vulnerable machines  
- Authorized training or challenge platforms  

No testing is performed against real-world systems, networks, or data without explicit permission.  
This repository exists solely for **security learning, experimentation, and defensive skill development**.
