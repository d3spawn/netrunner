# netrunner

**netrunner** is my personal cybersecurity portfolio.

It contains hands-on labs and projects I use to build and document my understanding of:
- Network security fundamentals
- Offensive and defensive security workflows
- Safe lab design and isolation
- Clear technical documentation

The focus of this portfolio is **learning by building** and **explaining decisions**, not collecting tools or certifications.

## Scope & Ethics

All work in this repository is conducted within controlled lab environments, intentionally vulnerable systems, or authorized challenge platforms.

No testing is performed against real-world systems, networks, or data without explicit permission.  
This repository exists solely for defensive learning, security research, and skill development.
